# Security policy

OpenGauge is experimental vehicle electronics. Do not use it as the only
source of safety information.

Do not publish credentials, vehicle identifiers, private CAN captures, or an
unpatched vulnerability in a public issue. Use GitHub's private vulnerability
reporting function for this repository when it is available. If it is not
available, open a public issue that asks the maintainer for a private contact
method. Do not include exploit details in that issue.

Include the affected commit, hardware revision, reproduction conditions, and
possible impact in a private report.

Only the latest commit on the default branch receives security fixes.
